Technologia's first workshop alpha for **Minecraft Java 1.21.1**. This is an early prototype; the wider progression and feature catalog are still in development.

## Downloads

Choose **one** jar matching your mod loader:

| Loader | Jar | Requirements |
| --- | --- | --- |
| Fabric | `technologia-fabric-1.21.1-0.1.0-alpha.1.jar` | Fabric Loader 0.16.9+ and Fabric API; Team Reborn Energy is bundled |
| NeoForge | `technologia-neoforge-1.21.1-0.1.0-alpha.1.jar` | NeoForge 21.1.80+ |
| Forge | `technologia-forge-1.21.1-0.1.0-alpha.1.jar` | Forge 52.0.28+ |

Use Java 21. Install the matching jar in the client's and server's `mods` folders. GitHub's automatically generated source archives are not installable mods.

## Included

- Coal/charcoal generation, energy buffering, raw-metal crushing and electric smelting.
- A bounded selective miner with filters, pause/rescan and owner checks.
- A 54-slot storage core, terminals and storage network cables.
- Tin, lead and resonite, with world generation and survival recipes.
- Shared machine UI, server balance configuration and `/technologia status`.
- Original prototype textures and recessed storage/terminal geometry.
- Separate Fabric, NeoForge and Forge energy/inventory adapters.

## Verification and limits

All three loader builds, shared energy unit tests and eight NeoForge server GameTests pass. Resource validation checks 165 shared JSON definitions. Client visual/playtesting, Fabric/Forge runtime tests and external modpack compatibility checks are still pending.

Storage is currently a plain inventory without item aggregation or autocrafting. Machines have fixed facing. The electric furnace does not award XP; energy is not retained when a machine is broken. Create's kinetic bridge, rack infrastructure, higher tiers, reactors, dimensions, equipment and draconic/chaotic endgame are planned. Draconic/chaotic cores are creative-only concept items.

See the [README](https://github.com/Thespiki/Technologia#readme) for the starter factory loop and the [project presentation](https://thespiki.github.io/Technologia/) for the roadmap.
