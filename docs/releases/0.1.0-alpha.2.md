Technologia's second workshop alpha for **Minecraft Java 1.21.1**. Version `0.1.0-alpha.1` and its source tag remain available.

## New in this version

- A searchable Nexus catalogue: combined counts for identical item components, name/count sorting, pages, single-item/stack withdrawal, shift-click transfers and cursor deposits.
- Server-side checks reject stale catalogue actions and disconnected terminal access. Each terminal still accesses one 54-slot core; multiple-core storage and autocrafting are future work.
- A native Field Guide with a connected nine-chapter atlas, 17 readable articles, sidebar, scrolling and keyboard navigation. Craft it from a book and copper ingot or use `/technologia guide` without operator permissions.
- Machines face the placing player and show an active front during processing. Storage blocks retain recessed geometry, and network cable arms follow their connections.
- Clearer machine screens with separate inputs and outputs, hidden unused slots, matching panel controls and progress bars clear of item slots. Empty storage/search results have their own uncluttered panel.
- Packaging protects previously delivered jars from replacement. New builds receive a new version folder and source tag.

## Install

Choose one jar matching your loader. Use Java 21 and Minecraft **1.21.1** on client and server.

| Loader | Jar | Requirements |
| --- | --- | --- |
| Fabric | `technologia-fabric-1.21.1-0.1.0-alpha.2.jar` | Fabric Loader 0.16.9+ and Fabric API; Team Reborn Energy bundled |
| NeoForge | `technologia-neoforge-1.21.1-0.1.0-alpha.2.jar` | NeoForge 21.1.80+ |
| Forge | `technologia-forge-1.21.1-0.1.0-alpha.2.jar` | Forge 52.0.28+ |

Back up an existing world before testing an alpha upgrade. Block/item IDs and inventory storage remain unchanged; facing/activity properties are new. World-upgrade playtesting is still pending.

## Verification and limits

Validation results are recorded in [VALIDATION.md](https://github.com/Thespiki/Technologia/blob/v0.1.0-alpha.2/docs/VALIDATION.md). The publication workflow requires all three builds, shared tests, resource checks and successful NeoForge server GameTests.

Local release packaging passed for all three loaders, along with two shared unit tests and all 18 NeoForge server GameTests. Initial NeoForge singleplayer playtesting covered storage connectivity, energy transfer, processing and miner filters. Client checks at small and maximized window sizes covered guide navigation, combined storage counts, empty search results and the corrected furnace layout. Broader interface testing, multiplayer, Fabric/Forge runtime and external modpack checks remain.

No Create kinetic bridge, autocrafting, higher-tier production, equipment or bosses are included yet. Draconic/chaotic cores are creative-only concept items. The electric furnace does not award XP, and broken machines do not retain energy.
