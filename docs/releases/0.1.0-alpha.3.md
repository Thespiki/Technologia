Technologia's factory expansion alpha for **Minecraft Java 1.21.1**. Earlier delivered jars and source tags remain available.

## New production and power

Ten new machine types extend the workshop beyond the original generator/crusher/furnace loop:

| Machine | Implemented behavior |
| --- | --- |
| Alloy Smelter | Three copper + one tin → four bronze; one iron + two coal dust → one steel. Two counted inputs, either slot order. |
| Metal Press | Iron, copper, gold, bronze and steel ingots → matching plates. |
| Sawmill | Ten vanilla wood families → six planks and one sawdust per input, including tagged stripped logs/wood and Nether stems. |
| Compactor | Bulk materials → storage blocks; sand → sandstone and clay balls → clay. |
| Centrifuge | Gravel → flint, clay → clay balls, moss → bone meal and cactus → slime. |
| Recycler | Iron/gold tools and armor → three matching nuggets. Consumes the original item's enchantments and components. |
| Biomass Generator | Sawdust, saplings, wheat, kelp or sugar cane → power; 20 FE/t at default settings. |
| Solar Generator | 16 FE/t in clear daytime with open sky in a skylit dimension. |
| Advanced Solar Generator | 64 FE/t under the same conditions. |
| Advanced Energy Cell | Stores 5,000,000 FE. The original cell remains at 1,000,000 FE. |

Bronze, steel, five plates, coal dust and sawdust link these machines through survival recipes. Nine sawdust can also be crafted into charcoal. The Survey Miner and advanced circuits now use workshop plates in their recipes.

The Crusher and the new processors use the reloadable `technologia:processing` recipe type, supporting counted item/tag ingredients, an optional byproduct, cycle time and FE per tick. Processing checks space for the entire result before spending power. Changes to a recipe or input identity reset progress; topping up the same input preserves it. The Electric Furnace continues to read vanilla smelting recipes.

## Logistics and storage

- Energy Conduits route power from Technologia generators and cells through up to 128 loaded conduits. Each supplier shares 200 FE/t across direct neighbors and conduit recipients. Generators can charge cells; cells cannot charge each other.
- Item Transfer moves up to eight items every eight ticks from its rear inventory toward its arrow. It supports a component-aware ghost filter, redstone pause, six directions and vanilla sided inventory rules. Right-click with a sample to filter; empty-handed use clears it.
- The configuration wrench rotates machines without breaking their contents and cycles Item Transfer directions. Crouch-use a machine to inspect its energy.
- Nexus terminals now combine up to four connected cores, for 54–216 backing slots. Each core retains its own saved inventory. Direct core access stays local to that core. Adding, removing or replacing a connected core invalidates the current terminal view; reopen it to refresh capacity.
- Networks with more than four cores or 128 connected network blocks fail closed. Storage never moves items into a separate catalogue-owned inventory.

## Models, building and guidance

All 17 machine types receive distinct baked three-dimensional geometry: open presses and compactors, saw housings, centrifuge drums, solar panels, exposed cell coils, miner assemblies, recessed drive racks, and a freestanding terminal with keyboard. Machine and decoration collision/selection shapes follow their model geometry. A shared material palette ties them to the existing industrial style. Active indicators change appearance; moving mechanisms are not included yet.

Ten matching building blocks are craftable: Steel Casing, Bronze Casing, Industrial Bricks, Steel Grate, Hazard Block, Engineering Lamp, Steel Pillar, Ventilation Grille, Control Panel and Reinforced Glass. Lamps emit level-15 light; the remaining building blocks are decorative.

The native Field Guide grows to **32 articles in nine chapters**, covering recipes, power, transfer filters, four-core storage, diagnostics and datapack settings. **20 vanilla advancement milestones** record obtaining workshop equipment. They persist with the player, without recipe gates or repeatable item rewards.

## Install and upgrade

Choose one jar matching your loader. Use Java 21 and Minecraft **1.21.1** on client and server.

| Loader | Jar | Requirements |
| --- | --- | --- |
| Fabric | `technologia-fabric-1.21.1-0.1.0-alpha.3.jar` | Fabric Loader 0.16.9+ and Fabric API; Team Reborn Energy bundled |
| NeoForge | `technologia-neoforge-1.21.1-0.1.0-alpha.3.jar` | NeoForge 21.1.80+ |
| Forge | `technologia-forge-1.21.1-0.1.0-alpha.3.jar` | Forge 52.0.28+ |

Back up existing worlds before upgrading an alpha. Existing registry IDs and machine inventory layouts are retained. Older unfinished processing cycles may restart under the new recipe state format; stored inventory is not consumed by that reset. Existing ore generation still affects only newly generated chunks.

The restart-required config now governs combustion/biomass output, Electric Furnace costs and miner settings. Crusher costs and the new processing costs come from datapack recipes. Check custom pack balance after upgrading. Broken machines drop their inventory but do not retain stored energy; the Electric Furnace still does not award XP.

## Verification and remaining limits

All three loader builds passed, and the local NeoForge server suite passed all **38 required GameTests**, covering the workshop, interfaces, new production/logistics/storage behavior and generated shapes. Solar obstruction checks also account for a newly placed roof immediately. Targeted NeoForge client checks passed for the models, alloy UI, conduit power, item transfer, combined storage and wrench; results belong in [VALIDATION.md](https://github.com/Thespiki/Technologia/blob/main/docs/VALIDATION.md). The publication workflow requires three loader builds, shared tests, resource checks and an explicit successful NeoForge server GameTest summary.

Fabric and Forge builds do not establish runtime or modpack compatibility. Power adapters provide FE on Forge/NeoForge and Team Reborn Energy on Fabric; conduit delivery to external endpoints still needs representative pack tests. Conduits have no external input buffer. Item Transfer supports vanilla `Container`/sided inventories; capability-only third-party inventories need further adapters.

Create kinetic integration, JEI/EMI/REI displays, fluids/gases, storage disks, autocrafting, configurable machine sides, moving machinery, reactors, equipment and bosses remain future work. Draconic and chaotic cores remain creative-only concept items. Decorative sockets and control panels do not provide unimplemented side configuration or factory controls.
